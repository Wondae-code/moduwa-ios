## 묶음 나눔 — 화면 단위

한 묶음 = 커밋 묶음 = 빌드 한 번 = QA 한 번. 화면이 같으면 같은 파일을 만지므로 함께 한다.

### 1묶음 · 버그 둘 (먼저)

UI를 건드리기 전에 잡는다. 화면이 바뀐 뒤에 버그를 재현하면 무엇 때문인지 헷갈린다.

**#15 글자 크기 → 메인 복귀 — 원인 확인됨**

`moduwa/Services/AccessibilitySettings.swift` 의 `applyTextScale(_:)` 가

```swift
if let size = scale.dynamicTypeSize { dynamicTypeSize(size) } else { self }
```

이다. `@ViewBuilder` 의 if/else 는 `_ConditionalContent` 를 만들어 **분기가 바뀌는 순간 뷰
정체성이 바뀐다**. 이 모디파이어가 `RootView.body` 의 `tabs` 전체에 걸려 있어서(`RootView.swift:69`),
**시스템 ↔ 크게**로 넘어갈 때 SwiftUI 가 트리를 통째로 새로 만들고 각 탭 `NavigationStack` 의
경로가 날아간다 → 메인으로 돌아간다.

- 고칠 방향: `transformEnvironment(\.dynamicTypeSize)` 처럼 **항상 같은 모디파이어 하나**가
  걸리게 바꾼다. 분기가 없어지면 정체성도 안 바뀐다.
- 진단 검증: 이 원인이면 **크게 ↔ 더 크게는 멀쩡해야 한다**(같은 분기). QA 보고가 그런지
  확인하면 진단이 바로 갈린다.

**#4 홈 최신 피드 — 원인 미상, 정렬 규칙일 가능성**

홈 "여행자 리뷰" 섹션은 리뷰(서버 정렬)와 게시글(**항상 최신순, 정렬 파라미터 없음**)을 따로
받아 `HomeViewModel.feedItems` 에서 섞는다. 기본 정렬이 `.recommended`(반응 수) 라서 새 글이
반응 수에 밀려 아래로 내려갔을 가능성이 크다 — **버그가 아니라 정렬 규칙**일 수 있다.
재현 조건(어떤 글이 언제 안 보였는지)을 받아 판단한다.
