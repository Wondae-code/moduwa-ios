# 백엔드 요청 — 댓글 수정·삭제 (2026-08-31)

> **처리 완료(같은 날, prod 배포)** — 네 라우트 전부. 후기 댓글도 미루지 않고 함께 왔고,
> `COMMENT_SELECT` 에 `isMine` 이 실렸다(목록·작성·수정 응답, 비로그인 false).
> `reviews.comment_count` 는 삭제와 같은 트랜잭션에서 `-1` 하고 `greatest(…, 0)` 으로 감쌌다.
> ⚠️ 서버가 덧붙인 두 가지: **빈 body 수정은 400**(수정이 두 번째 삭제 경로가 되지 않게),
> **삭제는 멱등이 아니다**(두 번 지우면 404 — 앱은 그것을 "이미 없어졌다" 로 다룬다).
> 부수 효과: 형식이 틀린 `postId` 가 500 → 404 로 바뀌었다(앱에 500 별도 처리는 없었다).
> `updatedAt` 은 댓글에 아직 없다 — "수정됨" 표시가 필요해지면 그때 요청한다.

앱팀입니다. **내가 쓴 댓글을 고치거나 지울 길이 없습니다.** 게시글은 `isMine` 을 주신 덕에
수정·삭제가 붙었는데, 댓글은 조회·작성만 있어서 앱에서 만들 수 있는 것이 없습니다.

게시글 댓글과 후기 댓글이 **다른 테이블·다른 라우트**라 둘 다 적었습니다. 급한 쪽은 게시글
댓글이고(`isMine` 이 이미 옵니다), 후기 댓글은 여유 있을 때여도 됩니다.

## 확인한 현황 (앱팀이 코드로 확인)

| | 게시글 댓글 | 후기 댓글 |
|---|---|---|
| 라우트 | `GET`·`POST /v1/posts/:postId/comments` | `GET`·`POST /v1/reviews/:reviewId/comments` |
| 수정·삭제 | **없음** | **없음** |
| `isMine` | **있음** (`POST_COMMENT_SELECT`, coalesce 처리됨 — 감사합니다) | **없음** (`COMMENT_SELECT` 에 소유 표시가 없습니다) |
| 댓글 수 | `count(*)` 서브쿼리 (`POST_SELECT`) — 지우면 저절로 맞습니다 | **캐시 컬럼** `reviews.comment_count` (작성 시 `+1` — `app.ts:1164`) |

---

## 요청 1. 게시글 댓글 — 수정·삭제

```jsonc
// PATCH /v1/posts/:postId/comments/:commentId   🔒
{ "body": "고친 내용" }        // → 200, 갱신된 댓글(작성 응답과 같은 모양)

// DELETE /v1/posts/:postId/comments/:commentId  🔒
                               // → 204
```

- **본인 댓글만.** 남의 댓글·없는 댓글 모두 **`404`** 로 부탁드립니다 — 게시글 수정·삭제와
  같은 규칙이라 앱 분기가 하나로 끝나고, 존재 여부도 새지 않습니다.
- 검증은 작성과 동일하면 충분합니다(트림 후 빈 문자열이면 `400`, 길이 상한 초과면 `400`).
- 삭제는 **하드 삭제**로 부탁드립니다. "삭제된 댓글입니다" 자리를 남기는 편이 대화 맥락에는
  좋지만, 지금 댓글은 대댓글이 없어 남길 맥락이 없습니다.
- 응답에 `isMine` 이 그대로 오면(작성 응답처럼) 앱이 갱신된 줄을 바로 그립니다.

## 요청 2. 후기 댓글 — 수정·삭제 + `isMine`

```jsonc
// PATCH  /v1/reviews/:reviewId/comments/:commentId   🔒  → 200
// DELETE /v1/reviews/:reviewId/comments/:commentId   🔒  → 204
```

- `COMMENT_SELECT` 에도 **`isMine` 한 줄**을 부탁드립니다(게시글 댓글과 같은 형태).
  없으면 앱이 어느 댓글이 내 것인지 몰라 메뉴를 띄울 수 없습니다.
- ⚠️ **`reviews.comment_count` 를 같은 트랜잭션에서 `-1`** 해 주세요. 작성 때 `+1` 하고 있어
  (`app.ts:1164`) 삭제만 하면 목록의 댓글 수가 실제보다 많아집니다. 앱은 그 값을 후기 카드에
  그대로 그립니다.

## 앱이 할 일 (라우트가 열리면)

- 댓글 줄에 `isMine` 이면 수정·삭제(길게 누르기 메뉴). 삭제는 되돌릴 수 없어 한 번 더 묻습니다.
- 지우면 목록에서 빼고 댓글 수를 줄입니다. 고치면 그 줄만 갈아끼웁니다.
- 화면: `PostDetailView`(게시글 댓글), `ReviewDetailView`(후기 댓글).

## 반만 하셔도 됩니다

시간이 촉박하면 **삭제만** 먼저 열어 주세요. 잘못 쓴 댓글을 지울 수 없는 것이 고칠 수 없는 것보다
불편합니다 — 앱은 열린 것만 메뉴에 띄우면 되고, `PATCH` 가 없으면 "수정" 을 빼면 그만입니다.
