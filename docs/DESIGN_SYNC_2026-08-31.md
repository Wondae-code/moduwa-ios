### A1. 추천 코스 테마 라벨이 시안과 다릅니다 (겹치는 것 1개)

`GET /v1/plan-options` 이 주는 라벨을 앱이 그대로 그립니다(문구를 앱에 넣지 않기로 한 기존 결정).

| | 값 |
|---|---|
| **서버(현재, 12개)** | 차박·캠핑 / 워터파크 / SNS 사진 / **자연과 함께** / 실내 / 전통과 역사 / 아름다운 풍경 / 쇼핑하기 / 문화·예술 / 미술 / 먹방 투어 / 야경이 예쁜 곳 |
| **시안(9개)** | 체험·액티비티 / SNS 핫플 / **자연과 함께** / 유명 관광지 필수 / 여유롭게 힐링 / 쇼핑 러버 / 문화·예술·역사 / 먹방 러버 / 여행지 느낌 물씬 |

겹치는 것은 `자연과 함께` 하나뿐이고 개수도 다릅니다.
→ **서버 사전을 시안에 맞출지, 시안을 서버에 맞출지** 정해 주세요. 앱은 어느 쪽이든 코드 변경이 없습니다.
(`code` 는 그대로 두고 `label` 만 바꾸면 저장된 플랜의 테마도 안전합니다.)
